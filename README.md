## Objective : To understand the interface of Adobe Photoshop and learn to use basic tools for creating designs with shapes, colours, and text.
Tools Used
Move Tool
Marquee Tool
Lasso Tool
Brush Tool
Eraser Tool
Shape Tool
Text Tool
Steps
Open Adobe Photoshop.
Create a new document with a size of 1200 × 800 pixels.
Use the Shape Tool to draw different shapes.
Apply different colours to the shapes.
Use the Text Tool to add a heading and student details.
Arrange the shapes and text properly.
Save the editable file in PSD format.
Export the final design as a JPG image.
