Objective

To learn photo editing techniques, including cropping, brightness and contrast adjustment, colour correction, and removal of small unwanted spots.

Tools Used
Crop Tool
Move Tool
Spot Healing Brush Tool
Brush Tool
Brightness/Contrast Adjustment
Color Balance Adjustment
Layers Panel
Steps
Open Adobe Photoshop.
Open a photograph using File → Open.
Duplicate the original layer using Ctrl + J.
Use the Crop Tool to remove unwanted areas.
Adjust brightness and contrast to improve the image.
Use Color Balance to correct the colours if required.
Use the Spot Healing Brush Tool to remove small unwanted spots.
Compare the edited image with the original image.
Save the editable file in PSD format.
Export the final edited image as a JPG.
