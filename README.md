# Practical 05 – Filters, Effects, Custom Brushes and Blending Modes

## Student Details

* Roll Number:CU25260192
* Course: BCA
* Semester: 3

## Objective

To understand and apply Photoshop filters, effects, custom brushes, blending modes, and layer styles to create creative artwork.

## Steps

1. Create a new document with a width of 1200 pixels and a height of 800 pixels.
2. Create a suitable background using the Gradient Tool or Shape Tool.
3. Add an image or design element to the canvas.
4. Apply at least two Photoshop filters to the artwork.
5. Create or import a custom brush and use it to add creative effects.
6. Apply at least two blending modes, such as Multiply, Screen, Overlay, or Soft Light.
7. Apply at least one Layer Style, such as Drop Shadow or Outer Glow.
8. Add creative text using the Text Tool.
9. Keep major design elements on separate, clearly named layers.
10. Save the project as a PSD file.
11. Export the final artwork as a PNG file.

* Move Tool
* Brush Tool
* Custom Brush
* Filter Gallery
* Gaussian Blur

  # Practical 06 – Complete Photoshop Project: Promotional Poster

## Student Details

* Name: Varnika 
* Roll Number: CU25260192
* Course: BCA
* Semester: 3

## Objective

To create a professional promotional poster by combining Photoshop skills learned in Modules 1 and 2.

## Steps

1. Create a new document with suitable dimensions for a promotional poster.
2. Choose a theme, such as a College Event, Workshop, Hackathon, Cultural Fest, or Photography Exhibition.
3. Create an attractive background using colors, gradients, or shapes.
4. Add relevant images using File → Place Embedded.
5. Use an advanced selection technique, such as the Quick Selection Tool, to select the main subject.
6. Apply a Layer Mask to control the visibility of the selected subject.
7. Add at least one Adjustment Layer to improve the colors or brightness.
8. Apply at least one Photoshop filter to an image or design element.
9. Apply at least one Blending Mode, such as Screen, Multiply, or Overlay.
10. Apply at least one Layer Style, such as Drop Shadow or Outer Glow.
11. Use a custom brush or brush-based effect to decorate the poster.
12. Add the event name, date, time, venue, and organizer or department name using the Text Tool.
13. Use attractive typography and arrange all elements neatly.
14. Maintain at least three layers and give them meaningful names.
15. Save the editable project as a PSD file.
16. Export the final promotional poster as a JPG file.

## Tools Used

* Move Tool
* Quick Selection Tool
* Brush Tool
* Text Tool
* Shape Tool
* Layer Mask
* Adjustment Layers
* Filters
* Blending Modes
* Layer Styles
* Custom Brushes
